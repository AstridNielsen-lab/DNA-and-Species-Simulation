# Análise de Características Físicas Baseadas em DNA

Este repositório contém o código-fonte e a documentação para um projeto de análise de características físicas humanas a partir de sequências de DNA.  O projeto foca na identificação de correlações entre genes específicos e traços físicos, considerando possíveis variações e mutações.  Atualmente, o sistema ainda não possui uma sequência de DNA carregada para análise, mas a estrutura está preparada para receber e processar tais dados.

## Funcionalidades

* **Entrada de Sequências de DNA:** O sistema foi projetado para receber sequências de DNA como entrada (formato a ser especificado futuramente, possivelmente FASTA).
* **Análise de SNPs (Polimorfismos de Nucleotídeo Único):** Identificação de SNPs relevantes associados a características físicas.
* **Predição de Características Físicas:**  Baseado nos SNPs identificados e em bancos de dados de referência (a serem especificados), o sistema prevê características físicas como cor dos olhos, cor do cabelo, altura e outras. A precisão das predições depende da qualidade e completude da sequência de DNA fornecida e dos bancos de dados usados.
* **Visualização de Dados:**  (Funcionalidade futura)  Visualização gráfica dos resultados, incluindo gráficos e representações visuais dos SNPs e suas associações com as características físicas.
* **Relatório Detalhado:**  Geração de um relatório completo contendo a sequência de DNA analisada, os SNPs identificados, as características físicas preditas e suas probabilidades.  O relatório explicará as bases genéticas das predições, incluindo referências bibliográficas.
